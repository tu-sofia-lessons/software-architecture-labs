Ядрото притежава данните; отчетите са верига if/elif в reports.py. Python 3.10+, без инсталации.

    python cli.py courses                # функция на ядрото
    python cli.py reports                # списък на наличните отчети
    python cli.py report csv             # отпечатва един отчет (csv | txt)
    python verify.py                     # сценарии за приемане (добави --punch за Втория удар)
