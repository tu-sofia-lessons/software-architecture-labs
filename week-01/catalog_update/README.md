# Ново издание на каталога (от екипа на каталога)

**Какво се променя.** В таблицата `courses` колоната `code` се преименува на `course_code`.

**Кой го прави.** Екипът на каталога. Те сменят само своя модул `courses/`:

* `repository.py` — новата версия на `courses/repository.py`
* `migration.py` — преименува колоната в базата

**Какво обещават.** `CourseService` и `CourseRepository` връщат курсовете точно както досега — с ключ `"code"`.

**Какво не обещават.** Код извън `courses/`, който чете таблицата `courses` директно със SQL.

**Ти не копираш нищо от тази папка.** `python ladder.py` сам прилага изданието върху копие на твоя код и проверява дали той още работи.
